# Competitive Analysis (draft)

> Draft based on general public knowledge of each product's positioning. Not yet checked against current official pages; features change often. To be refreshed with citations before being relied on.

| Product | Strength | Gap AbhiKnow can address |
|---|---|---|
| Elicit | AI-assisted paper search and data extraction | Papers only; no books, courses, or access orchestration |
| Consensus | Evidence-based answers from papers | Papers only; answer-centric rather than a workspace |
| NotebookLM | Source-grounded Q&A over user-supplied documents | Does not discover sources for you |
| ResearchRabbit | Citation-network exploration | Academic papers; limited reading and learning features |
| Zotero | Reference management, open source | Weak discovery and no learning layer |
| OpenAlex | Open scholarly metadata (used as a provider) | A data source, not a user product |
| Semantic Scholar | Paper search, citation context | Papers only |
| Google Scholar | Broad scholarly index | No API, no library or workspace features |
| Connected Papers | Visual paper graphs | Narrow scope |

## AbhiKnow differentiation

Multi-format discovery in one query; honest access classification (free vs paid vs restricted, with lawful alternatives); a reading and notes workspace; later, source-grounded AI, learning paths and a research completeness view. We do not copy any product's interface or proprietary functionality.
