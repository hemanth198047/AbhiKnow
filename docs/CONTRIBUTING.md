# Contributing

1. Work in small vertical slices; every slice ships with tests and docs.
2. Do not claim completion in `IMPLEMENTATION_STATUS.md` until the feature is tested.
3. No mandatory paid services. Record every new dependency in `LICENSING.md`.
4. No code that bypasses paywalls, DRM, CAPTCHAs, waiting periods or anti-bot protections.
5. Never fabricate provider data in code or fixtures presented as real; test fixtures must be labelled.
6. Branch from `main`, use clear commit messages, open a pull request.
