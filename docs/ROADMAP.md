# Roadmap

Each phase ends with: tests run, defects fixed, user journey verified, security reviewed, docs updated, limitations recorded.

| Phase | Theme | Key deliverables |
|---|---|---|
| 0 | Foundation | Repo assessment, requirements, architecture, data model, licensing and provider registers, local setup |
| 1 | Discovery MVP | Search UI, Spring Boot API, PostgreSQL, adapter framework, OpenAlex/Crossref/arXiv/Open Library/Gutenberg, normalization, dedup, ranking, access classification, detail pages |
| 2 | Library and reader | Auth, collections, bookmarks, notes, PDF/EPUB reader, reading progress, workspaces |
| 3 | Access orchestration | Access state machine, authorized downloads, human-action handoffs, validation, secure storage, legal alternatives |
| 4 | Local AI scholar | Ollama, embeddings, semantic search, grounded Q&A, citation verification, summaries |
| 5 | Learning | Goals, paths, prerequisites, modules, quizzes, flashcards, progress |
| 6 | Research completeness | Topic decomposition, coverage, evidence quality, gaps, dashboard |
| 7 | Multi-format | YouTube, podcasts, courses, news/RSS, GitHub |
| 8 | Automation | Saved searches, scheduled discovery, alerts |
| 9 | Collaboration | Shared workspaces, annotations, access control |
| 10 | Scale readiness | Only what measurements justify |

The MVP acceptance scenario (requirements section 32) gates work on Phases 4 and beyond.
